# Preview captures

Captured on 2026-10-25 from the deployed PureTV v2 app on a Xiaomi Mi Stick (MiTV-AESP0), Android TV 9.
The app language is English. These are genuine full-resolution device screenshots, copied without image edits.

- `home-en.png`: clock-only home, weather and the app shelf.
- `quick-settings-en.png`: the compact quick panel over the clock home, showing AirPlay and a resource snapshot.
- `settings-en.png`: System and about, with Language set to English.

Viewing/recommendation content is temporarily hidden by choosing the clock layout; the user's original viewing layout
is restored after capture. No viewing history, personal titles, local network addresses, account credentials or identifiers
are shown. The app language stays English as requested. App logos remain their owners' trademarks.

These captures establish the deployed Android TV interface on the named device. They do not establish LG/Samsung,
every Google TV firmware, or fresh renamed-package setup compatibility. See [testing scope](../INSTALL.md#compatibility).

`remote.svg` remains an original navigation diagram, not a device screenshot.
All documentation media stays outside APK/IPK/WGT runtime packages.
