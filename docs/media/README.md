# Preview media

`hero.svg` and `remote.svg` are illustrations. Every PNG is a genuine 1920 × 1080 screenshot of PureTV on a
Xiaomi Mi Stick (MiTV-AESP0), Android TV 9, with the interface set to English for the capture: `home-en.png`,
`settings-en.png`, `background-en.png` and `quick-settings-en.png` show v1.4.2, the others v1.4.

| File | What it shows |
| --- | --- |
| `recommendations-en.png` | Recent + recommended layout, Recommended tab, focus on the first card (see below). |
| `home-en.png` | The clock layout with the Automatic background photo at night: weather pill, date, glass clock, app shelf and the photo's credit. |
| `all-apps-en.png` | All Apps, with the home screen's apps, the other apps and a hidden app (dimmed). |
| `setup-en.png` | The setup guide's home screen layout step, with its preview. |
| `settings-en.png` | Settings → Home screen, as it opens: categories, the settings and the detail pane. |
| `background-en.png` | Settings → Home screen → Background photo: the preview and the photos to choose from. |
| `quick-settings-en.png` | The quick panel over the clock layout with its background photo. |
| `shortcuts-en.png` | One press down: the Shortcuts row and Other apps. |
| `screensaver-en.png` | The screensaver's clock and weather on black. |
| `light-en.png` | The home screen in the light theme. |

The only edit hides the city name, so the owner's location is not published: in `light-en.png` the weather line's city
is painted over with the surrounding background; in `home-en.png` and `quick-settings-en.png` the weather pill ends
after the conditions and the sky next to it is continued from the sky just below. No viewing history, account, network address or
device identifier appears. The language, theme and layout changed for the captures were set back afterwards.
`recommendations-en.png` was taken with a screenshot-only build (never released) whose Recommended row holds a fixed,
illustrative selection of well-known films, with their TMDB backdrops; the app named under each title is only an
example and does not say where the film streams. That build reads no viewing history. In normal use the row shows
what the installed streaming apps publish. App names, logos, film titles and artwork belong to their owners.
