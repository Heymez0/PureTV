# Artwork

All five SVGs are original English-language illustrations, not device screenshots or hardware test results.

- `hero.svg`: project cover and a simplified TV.
- `platforms.svg`: native Android and shared web architecture.
- `remote.svg`: arrow, OK, Back and long-OK navigation.
- `clock-home.svg`: sample clock home with synthetic weather and generic app labels.
- `oled-saver.svg`: sample black clock screensaver; the actual clock drifts during use.

Artwork is documentation-only and is excluded from APK/IPK/WGT packages.
